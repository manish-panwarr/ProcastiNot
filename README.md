TaskForge — Enterprise Collaborative Workspace 

Tech Stack
React • Node.js • Express.js • MongoDB • Redis (Upstash) • Socket.io • WebRTC • JWT • TailwindCSS and Nodemailer

Overview

TaskForge is a production-grade collaboration platform built to support modern team workflows through task management, role-based access control, team messaging, analytics dashboards, and automated notifications.

Unlike traditional task managers, TaskForge includes a serverless WebRTC-based peer-to-peer file sharing system that enables direct browser-to-browser transfers without routing files through application servers.

Enterprise-grade task management and collaboration platform featuring WebRTC peer-to-peer file sharing, Redis-powered caching, real-time communication, RBAC authorization, analytics dashboards, and automated workflow notifications.

**Key Features**

**Real-Time Collaboration**
Team workspaces
Role-Based Access Control (RBAC)
Task assignment & tracking
Team messaging using Socket.io

**WebRTC P2P File Sharing**
Browser-to-browser file transfer
Dynamic STUN/TURN configuration
16KB chunked streaming
Flow-control algorithm to prevent DataChannel buffer overflow
Zero server bandwidth usage

**Performance Optimization**
Upstash Redis caching
MongoDB aggregation pipelines
N+1 query elimination
Route-level code splitting
Optimized dashboard analytics

**Security**
JWT Authentication
Refresh Token Rotation
Token Blacklisting
HttpOnly Cookies
Rate Limiting
Helmet.js Protection

**Automation**
Deadline notifications
Background cron services
Redis-based deduplication
Email reminders
